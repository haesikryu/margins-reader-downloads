# 여백

**내 책을 담고, 읽던 자리에서 이어가는 PDF·EPUB 전자책 리더.**

[소개·사용법 페이지](https://haesikryu.github.io/margins-reader-downloads/) · [웹에서 바로 시작](https://margins-drive-sync.haesikryu.workers.dev/) · [Mac 앱 다운로드](https://github.com/haesikryu/margins-reader-downloads/releases/tag/v0.16.1)

이 저장소는 친구들과 공유하기 위한 **앱 다운로드·사용 안내** 공간입니다. 책 파일은 제공하지 않으며, 직접 보유한 PDF·EPUB을 가져와 읽습니다. GitHub 계정 없이 소개 페이지와 설치 파일을 이용할 수 있습니다.

## 가장 쉬운 시작

1. **[웹 서재 열기](https://margins-drive-sync.haesikryu.workers.dev/)** — 설치나 로그인 없이 시작합니다.
2. **책 가져오기** — DRM 없는 PDF·EPUB 파일을 선택합니다.
3. **표지 눌러 읽기** — 읽던 위치가 저장됩니다. 문장을 선택해 하이라이트·메모를 남기고 Markdown으로 내보낼 수 있습니다.

**나의 책장 → 책장 만들기**에서 관심사별 책장을 만들고, 책의 **더보기 → 책장에 담기**로 여러 책장에 넣을 수 있습니다. 독서 목표와 오늘 읽은 시간도 서재에서 확인합니다.

## 기기에 맞게 사용하기

| 기기 | 사용 방법 |
| --- | --- |
| Mac·Windows PC | 웹 서재를 엽니다. 지원 브라우저에서는 앱 설치 메뉴를 사용할 수 있습니다. |
| iPad·iPhone | Safari로 웹 서재를 연 뒤 **공유 → 홈 화면에 추가**를 선택합니다. 이후 홈 화면의 여백을 엽니다. |
| Android | Chrome으로 웹 서재를 연 뒤 브라우저 메뉴의 **앱 설치 / 홈 화면에 추가**를 사용합니다. |
| Apple Silicon Mac | 아래 독립 앱을 설치할 수 있습니다. |

현재 독립 설치 파일은 **Apple Silicon(M1 이상), macOS 13 이상용 v0.16.1**입니다. Intel Mac·Windows·Android의 독립 설치 파일과 App Store용 iOS 앱은 제공하지 않습니다. iPhone·Android 실기기의 모든 흐름을 검증한 것은 아닙니다.

### Mac 독립 앱 설치

1. [MarginsReader-0.16.1-mac-arm64.dmg](https://github.com/haesikryu/margins-reader-downloads/releases/download/v0.16.1/MarginsReader-0.16.1-mac-arm64.dmg)를 받습니다.
2. DMG를 열고 **여백.app**을 **Applications(응용 프로그램)** 폴더에 드래그합니다.
3. 응용 프로그램에서 여백을 엽니다. 기존 사용자는 먼저 서재를 ZIP으로 백업하고 앱을 정상 종료한 뒤 교체합니다.

이 앱은 **Apple 공증을 받지 않은 개인 개발 배포본**으로 macOS가 실행을 차단할 수 있습니다. 설치 없이 사용하는 웹 버전도 같은 서재 기능을 제공합니다. 보안 설정을 끄거나 터미널 명령으로 검사를 우회할 필요는 없습니다. 공개 배포용 DMG에는 사용 안내와 제3자 라이선스를 함께 담았습니다.

GitHub 릴리스의 **Assets**에서 `.dmg`를 선택하세요. 자동으로 표시되는 **Source code (zip/tar.gz)**는 이 안내 페이지의 소스이며 Mac 설치 파일이 아닙니다. 설치 파일의 SHA-256과 제3자 라이선스도 릴리스에 함께 제공합니다.

## 여러 기기에서 같은 서재 이어 읽기

동기화는 선택 사항입니다. 사용하려면 **각자의 Google 계정**을 연결합니다.

1. 서재의 **Google Drive 설정**을 엽니다. Mac에서 서비스 주소를 요청하면 `https://margins-drive-sync.haesikryu.workers.dev`를 입력합니다.
2. **Google 계정 연결 · 서재 합치기**를 누르고 본인의 Google 계정으로 연결합니다.
3. 다른 기기에서도 **같은 Google 계정**으로 연결한 뒤 서재에서 **동기화했습니다** 표시를 기다립니다.

책·나의 책장·읽던 위치·메모·독서 기록을 함께 사용할 수 있습니다. 처음 연결할 때 기존 기기의 서재와 본인의 Drive 서재를 합칩니다. 이후 책·메모의 삭제도 연결된 기기에 반영됩니다. 친구의 책이나 제작자의 서재가 자동으로 공유되는 기능은 아닙니다.

동기화는 앱이 열려 있고 인터넷에 연결된 상태에서 진행하며, 읽기·편집 중에는 기다렸다가 서재로 돌아오면 반영합니다. Google 로그인 화면의 요청 권한을 확인한 뒤 연결하세요. 연결이 거부되면 웹에서 로컬 독서는 계속 사용할 수 있습니다. 앱의 기기 세션은 30일이며, 만료되거나 권한을 철회하면 재연결이 필요합니다. 서비스·Google 저장 공간의 무료 한도에 따라 동기화가 제한될 수 있습니다.

책 원본은 본인의 Google Drive 앱 전용 공간에 저장되어 일반 Drive 파일 목록에는 보이지 않습니다. 동기화 서버가 전송 데이터를 처리하므로 종단 간 암호화 서비스는 아닙니다. 자세한 내용은 [개인정보처리방침](https://margins-drive-sync.haesikryu.workers.dev/privacy/)을 확인하세요.

## 책과 기록 보관하기

- **서재 백업**으로 책·읽던 위치·메모·독서 기록·책장이 포함된 ZIP을 저장합니다.
- 다른 기기로 옮길 때는 **백업 복원**으로 ZIP을 가져옵니다. 기존 서재와 합칩니다.
- 메모만 따로 보관하려면 책의 **Markdown 내보내기**를 사용합니다.

브라우저 사이트 데이터나 앱 데이터를 지우면 기기에 저장한 서재가 사라질 수 있습니다. 앱 삭제·기기 변경 전 ZIP을 보관하세요. 오프라인 읽기는 앱과 책 파일이 해당 기기에 준비된 뒤 사용할 수 있습니다.
